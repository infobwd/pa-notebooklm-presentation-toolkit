# Slide Deck Workflow

1. เลือก Script
2. เลือก Core Sources
3. เพิ่ม Visual Evidence
4. Chat QA
5. Generate Draft
6. ตรวจ TARGET/ACTUAL
7. ตรวจภาพหลักฐาน
8. ตรวจ Storyline
9. แก้ Source หากผิดทั้งชุด
10. Generate Final

## เมื่อควร Generate ใหม่

- Storyline ผิด
- ประเด็นหลักถูกลดความสำคัญ
- ใช้ข้อมูลข้ามช่วงเวลาแบบผิด
- ภาพ AI แทนหลักฐานหลายจุด

## เมื่อแก้เฉพาะสไลด์ได้

- ตัวสะกด
- รูปเดียวผิด
- ข้อความยาวเกิน
- layout ไม่เหมาะ
