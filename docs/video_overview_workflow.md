# Video Overview Workflow

1. ให้ Slide Deck ผ่าน QA ก่อน
2. ใช้ Script เดียวกับเวลาที่ต้องการ
3. เลือกภาพคน/กิจกรรมจริงเป็นหลัก
4. ใช้ Screenshot เป็น B-roll
5. ใส่ Steering Prompt
6. Generate Draft
7. ตรวจเสียง/ภาษา
8. ตรวจ ACTUAL
9. ตรวจภาพ evidence
10. Generate Final

## Visual Ratio แนะนำ

ให้ภาพคน/กิจกรรม/สถานที่จริงมีน้ำหนักมากกว่าภาพระบบ

## Narration

ควร:
- เป็นธรรมชาติ
- สุภาพ
- ไม่อ่านรายงาน
- มีจังหวะคิด/เชื่อม/สรุป

## Final Frame

จบด้วยผลกระทบต่อผู้เรียน ผู้รับบริการ หรือองค์กร ไม่จบด้วยหน้าจอซอฟต์แวร์
