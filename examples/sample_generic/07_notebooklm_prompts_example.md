# NotebookLM Prompts — Fictional Sample

## Chat QA

> ตรวจ Sources ของนายตัวอย่าง การศึกษา แล้วจัดข้อมูลเป็น FACT / TARGET / ACTUAL / CONTEXT / PENDING ระบุข้อมูลที่ยังขาด และห้ามใช้ข้อมูลจากบุคคลอื่น

## Slide Deck

> สร้าง Slide Deck ภาษาไทยสำหรับนายตัวอย่าง การศึกษา ผู้อำนวยการโรงเรียนตัวอย่างพัฒนา ความยาวการนำเสนอไม่เกิน 5 นาที
>
> Narrative: Context → Development Need → READ Model → Classroom/PLC → ACTUAL Results → Supporting Systems → Continuous Improvement → Closing
>
> ใช้ภาพจริงก่อนภาพสร้าง ห้ามสร้างภาพ AI แทนกิจกรรมจริงหรือ Screenshot
>
> แยกให้ชัด:
> - 62% = CONTEXT
> - 75 / 100 / 80 = TARGET
> - 80 / 100 / 85 = ACTUAL
> - การขยายผลภายนอก = PENDING
>
> ให้ผลลัพธ์และ Student Journey มีน้ำหนักมากกว่าระบบดิจิทัล
