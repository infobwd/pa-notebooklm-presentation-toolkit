# Final QA Checklist

## Identity
- [ ] ชื่อถูกต้อง
- [ ] ตำแหน่ง/วิทยฐานะ/หน่วยงานถูกต้อง
- [ ] รอบประเมินถูกต้อง

## Evidence
- [ ] ทุก ACTUAL มีหลักฐาน
- [ ] TARGET ไม่ถูกเรียกว่า ACTUAL
- [ ] CONTEXT ไม่ถูกเรียกว่า “ผลสำเร็จ” โดยอัตโนมัติ
- [ ] PENDING ยังไม่ถูกเติมด้วยการคาดเดา

## Storyline
- [ ] ปัญหา/ความต้องการชัด
- [ ] กระบวนการพัฒนาชัด
- [ ] ผลลัพธ์เป็นแกน
- [ ] ระบบ/นวัตกรรมเป็นตัวสนับสนุน ไม่แย่งแกนหลัก

## Visual
- [ ] ภาพหลักฐานจริงตรงกับข้อความ
- [ ] ไม่มีภาพ AI แทนหลักฐาน
- [ ] Screenshot ปกปิดข้อมูลลับ
- [ ] ไม่เปิดเผยข้อมูลส่วนบุคคลเกินจำเป็น

## Slide Deck
- [ ] ข้อความไม่แน่น
- [ ] หนึ่งสไลด์มี message หลักเดียว
- [ ] เวลาอยู่ในกรอบ

## Video
- [ ] เสียง/ภาษาเหมาะสม
- [ ] ภาพคน/กิจกรรมจริงมีน้ำหนักมากกว่าหน้าจอระบบ
- [ ] ไม่อ่านรายงานเป็นข้อ ๆ
- [ ] จบด้วยผลกระทบ ไม่จบด้วยฟีเจอร์ระบบ

## Isolation
- [ ] ไม่มีชื่อ/ข้อมูลจากตัวอย่างหรือบุคคลอื่นปะปน
