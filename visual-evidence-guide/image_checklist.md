# Image Checklist

## Identity
- [ ] ภาพผู้รับการประเมิน
- [ ] ภาพสถานศึกษา/หน่วยงาน

## Process
- [ ] Model/Framework
- [ ] กิจกรรมพัฒนางานจริง
- [ ] การมีส่วนร่วม
- [ ] การติดตาม/สะท้อนผล

## Results
- [ ] กราฟ ACTUAL
- [ ] Before/After หรือ Journey
- [ ] ผลงาน/ชิ้นงาน

## Systems
- [ ] Screenshot ระบบหลัก
- [ ] ปกปิด credential/IP/token/ข้อมูลลับ

## Recognition
- [ ] รางวัล/หนังสือรับรองที่เกี่ยวข้องจริง

## Privacy
- [ ] ไม่เปิดเผยข้อมูลส่วนบุคคลเกินจำเป็น
- [ ] ปกปิดชื่อ/เลขประจำตัวของผู้เรียนเมื่อไม่จำเป็น
