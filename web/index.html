PHASE 2.2 · EXTERNAL AI BRIDGE

ถาม AI ภายนอก → รับ JSON → Import เข้าระบบ

ใช้ Prompt มาตรฐานเพื่อให้ AI ภายนอกอ่านเอกสารของคุณและตอบกลับเป็น JSON ที่เว็บนี้นำเข้าได้

1 คัดลอก JSON Prompt

นำ Prompt นี้ไปใช้กับ ChatGPT, Gemini, Claude หรือ AI อื่น พร้อมแนบเอกสาร PA/รายงาน/หลักฐานที่ต้องการให้ช่วยสกัดข้อมูล

สำคัญ: ให้ AI ตอบเป็น JSON เท่านั้น และอย่าให้ AI เดาตัวเลข ACTUAL หรือหลักฐานที่ไม่มีในเอกสาร
2 วาง JSON ที่ AI ตอบกลับ
ยังไม่ได้ตรวจ JSON
ขอบเขตความน่าเชื่อถือ

การ Import ช่วยกรอกฟอร์มเท่านั้น ไม่ถือว่า AI ได้ยืนยันหลักฐาน ผู้ใช้ยังต้องตรวจ FACT / TARGET / ACTUAL / CONTEXT / PENDING กับเอกสารจริงก่อน Final
